# スパ人 業者共有用 追加メモ（2026-07-29）

このメモは、現時点のスパ人モックアップを業者さんへ共有するための追加仕様です。  
既存の `docs/spajin_vendor_spec.md` と `docs/ab_test_mock_spec.md` に追記する想定です。

## 1. 現在のモックURL

- 本編想定：`https://tadaaki-hub.github.io/spajin/`
- A/Bモック：`https://tadaaki-hub.github.io/spajin/ab-test.html`

GitHub Pages反映にはpush後、数分かかる場合があります。

## 2. 最新モックの方向性

現在のモックは、単なる施設検索ではなく「スパ神と会話しながら今夜の一湯を選ぶ」体験を検証するものです。

主な体験：

- 起動時にランダムで1人のスパ神が登場
- そのスパ神が最後まで案内する
- 各質問を選ぶと、質問の直下でスパ神が反応
- 最後に施設が `TONIGHT'S ORACLE` としてポップアップ表示される
- 施設表示後、ユーザーが「合っていたか」を3択で回答
- さらに自由記入欄で気になることを書ける
- スパ神の返信はGoogleマップボタンの上に読みやすく表示

## 3. デザイン方針

現在のサイトトーンは白基調です。

- 背景：白〜薄いベージュ
- 温泉感：湯気、淡い金色、薄い水色、檜色
- 文字：白背景でも読みやすい濃色
- 結果ポップアップ：施設セルを主役にする
- `TONIGHT'S ORACLE` 内には半透明のチャット履歴欄を置かない

## 4. 診断ロジックの考え方

施設ごとの個別コードは作りません。  
スプレッドシート/CSV/JSONの施設マスターを読み、共通ロジックで候補を抽出します。

質問の見た目は増やしても、内部分類は増やしません。

例：

- Q1は6択表示だが、内部判定は `A/B/C` の3分類
- Q2は4択表示だが、内部判定は `A/B` の2分類
- Q3は都府県・エリア選択
- Q4は任意の自由入力

これにより、ユーザー体験は豊かにしつつ、施設数が300以上に増えても実装負荷を抑えます。

## 5. 「別の一湯へ」の仕様

「別の一湯へ」を押した場合：

- 施設だけを切り替える
- スパ神は変えない
- 同じスパ神が続けて案内する

理由：

- 毎回スパ神が変わると、会話している感覚が切れるため
- セッション内の案内役としての一貫性を保つため

## 6. 施設表示後のfeedback仕様

施設表示後に以下の3択を表示します。

- かなり合ってる
- 少し気になる
- 今日は違うかも

さらに自由記入欄を表示します。

入力例：

- 混み具合が気になる
- サウナも入りたい
- 露天はある？
- 岩盤浴で長く過ごしたい

モックでは固定ルールで返信しています。  
本番では、この入力をCloud Run経由でOpenAI APIに渡し、選ばれているスパ神の口調で返答します。

## 7. Googleマップ導線

モックでは施設名・エリア・温泉を使い、Googleマップ検索URLを生成しています。

本番では施設マスターに以下の列を追加することを推奨します。

```text
google_map_url
```

この列がある場合、フロントエンドは検索URLではなく正式なGoogleマップURLを使用します。

## 8. API構成の想定

フロントエンドにAPIキーは置きません。

```text
Webサイト
  ↓
Cloud Run API
  ↓
Gemini API / OpenAI API
```

役割分担：

- Gemini API：口コミ収集・要約・タグ化などの下処理
- OpenAI API：最後のキャラ口調生成、feedbackへの会話返答

## 9. 業者さんへ依頼したい実装方針

- 施設ごとの個別コードを書かない
- 施設マスターCSV/JSONを読み込むデータ駆動型にする
- 施設選定とスパ神の演出を分離する
- スパ神は施設固定にしない
- 初回登場したスパ神は、セッション中できるだけ固定する
- `別の一湯へ` は施設だけ変更し、スパ神は固定
- feedbackログを取得できるようにする
- GoogleマップURLは施設マスター側で管理できるようにする

## 10. 業者さんにGitHubを共有する方法

方法は主に2つあります。

### A. リポジトリを公開したままURLを共有する

リポジトリがPublicの場合、以下のURLを送るだけで閲覧できます。

```text
https://github.com/tadaaki-hub/spajin
```

あわせてモックURLも送ります。

```text
https://tadaaki-hub.github.io/spajin/ab-test.html
```

この方法が一番簡単です。

### B. 業者さんをCollaboratorに追加する

リポジトリがPrivateの場合、または業者さんにも編集・pushしてもらう場合はこちらです。

手順：

1. GitHubで `tadaaki-hub/spajin` を開く
2. `Settings`
3. `Collaborators and teams`
4. `Add people`
5. 業者さんのGitHubアカウント名またはメールを入力
6. 権限を選ぶ

推奨権限：

- 見るだけ：Read
- 実装してもらう：Write
- 管理まで任せる：Maintain

最初は `Write` で十分です。
