# スパ人（スパジン）

スーパー銭湯・日帰り温泉を案内する温浴コンシェルジュのモックアップです。

## 概要

- 5人の「スパ神」キャラクターが登場
- 湯気の中からランダムで1人が登場し、最後まで案内
- 占い風の3つの質問で、今夜の気分に合う温浴施設を提案
- スマホ主体の1ファイルSPA
- キャラクター画像・湯けむり演出・ゲーム風オープニングを実装

## 現在の設計方針

- 近場・遠出の `q3_type` 判定は廃止
- 3つ目の条件は「都府県・エリア選択」に変更
- 施設ごとの個別コードではなく、スプレッドシート/CSV/JSONを読み込むデータ駆動型を想定
- 施設選定とスパ神キャラクター選定を分離
- 最後の施設紹介キャラは、施設タグから候補化して重み付きランダムで選ぶ想定
- 紹介文は施設ごとの固定文ではなく、キャラクター別テンプレートに施設情報を差し込む方式
